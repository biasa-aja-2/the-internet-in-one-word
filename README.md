## The word

> **Oops**

## Why this word

The whole internet, in one beat, is one long accident. Every viral post,
every leaked screenshot, every reply sent to the wrong group chat, every
typo that became a meme, every "delete this" that was already
screenshotted — the internet runs on oops. It is funny by itself with no
explanation needed, it says something true about the internet as a whole
rather than one app or one mood, it is not the first obvious word anyone
reaches for, and at four letters it lands before the reader has time to
think. It makes you laugh, then nod.

## Run it

```sh
python3 main.py
```

Writes `Oops` (4 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`). Pure Python stdlib, no dependencies.
